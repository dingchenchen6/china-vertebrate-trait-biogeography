# 中国陆生脊椎动物群落性状格局与驱动机制
## 研究设计文件 / Research Design Document

**版本** v1.0 | **日期** 2026-08-01 | **负责人** Chenchen Ding

---

## 0. 一句话定位 / One-sentence positioning

> **恒温与变温脊椎动物的群落性状受不同环境过滤器支配——变温类群被"热"过滤、恒温类群被"能量与结构"过滤；而在人类活动强烈的区域，这些自然过滤器正被人为过滤器系统性替代。**
>
> Thermoregulatory mode predicts *which* environmental filter governs assemblage trait composition — thermal energy for ectotherms, productivity and habitat structure for endotherms — and anthropogenic pressure is progressively *replacing* these natural filters, most strongly in endotherms.

## 1. 已有研究与我们的差距 / State of the art and the gap

### 1.1 两篇直接对标文献 / The two benchmark papers

| | **Huang et al. 2023, *The Innovation*** 4(1):100379 | **Sun et al. 2025, *Zoological Research*** |
|---|---|---|
| 物种数 | 2,430（两栖466、蜥蜴211、鸟1,177、兽576） | 2,334（两栖398、爬行211、兽541、鸟1,184） |
| 分布数据 | IUCN 范围图（ORIGIN 1/2/5/6；PRESENCE 1/2/4/5；SEASONAL 1/2） | IUCN 范围图 + GBIF 记录补充 |
| 网格 | 50 km Behrmann 等积网格，3,888 格 | 0.5°×0.5°（约 50×55 km） |
| 性状指标 | FRic / FEve / FDiv / FDis / RaoQ；NRI / NTI | 性状体积（sum of variance）、性状密度（mean NN distance）、演化独特性 |
| 驱动因子 | 现代温度、降水、**LGM 温度/降水变化**、海拔差、史前人口密度（10,000 BC） | MAT、MAP（其余因共线性剔除）、物种丰富度、演化独特性 |
| 统计模型 | `spaMM` 空间混合效应模型 | GLS + 空间相关结构（exp/gauss/spherical），AIC 选优 |
| 核心结论 | 华南功能丰富度高；北方/西部谱系聚集、功能分异高；LGM 剧烈变化 → 谱系聚集、FRic 低、FDiv/FEve 高 | 华南/西南为"博物馆+摇篮"；青藏高原性状体积大但密度低（生态位扩张）；两栖类对环境最敏感 |

### 1.2 二者共同的五个空白 / Five shared gaps

1. **没有机理性的跨类群假设。** 两文都只描述"效应因类群而异"，未从**恒温/变温（thermoregulatory mode）**这一第一性原理出发提出可证伪的预测，也未做**类群×驱动因子交互作用的正式统计检验**。
2. **完全忽略当代人类活动。** Huang 用的是**史前**（公元前 10,000 年）人口密度；Sun 只用 MAT/MAP。**当代土地利用、人类足迹、生境破碎化对群落性状的过滤作用无人检验**——而这恰是保护决策最需要的部分。
3. **单一空间粒度。** 均未检验尺度依赖性（MAUP）；群落构建理论明确预测过滤信号随粒度变化。
4. **CWM–环境回归的统计学陷阱未处理。** 群落加权平均值对环境做回归会产生严重膨胀的第一类错误（Peres‑Neto et al. 2017；ter Braak et al. 2018 的 max test / 四角法），两文均未采用正确的置换检验框架。
5. **性状维度狭窄。** 两文以生活史性状为主；未系统分解**形态、食性、活动节律、生境宽度、热生理**等多个功能维度对不同环境轴的差异化响应。

## 2. 科学问题与假设 / Scientific questions and hypotheses

### 核心科学问题 / Core question

> 跨越中国的环境梯度，**决定脊椎动物群落性状组成的环境过滤器身份与强度，是否可由类群的体温调节模式（恒温 vs 变温）与扩散能力预测？人类活动是否在系统性地替代这些自然过滤器？**

### 假设体系 / Hypothesis framework

#### **H1｜热约束不对称假说（Thermal‑constraint asymmetry）**
**机理**：内温性使恒温动物在生理上与环境温度解耦，但代价是极高的能量需求；变温动物体温随环境变化，其性状（体型、活动节律、繁殖模式、热耐受）直接受热环境筛选。

- **H1a**：变温类群（两栖、爬行）的 CWM 与**热能量轴**（年均温、最冷月低温、温度季节性）的耦合强度显著高于恒温类群。
- **H1b**：恒温类群（鸟、兽）的 CWM 与**能量供给/生境结构轴**（NPP、NDVI、生境异质性、林地占比）的耦合强度显著高于变温类群。
- **检验**：分层贝叶斯/GLS 模型中 `环境 × 体温调节模式` 交互项；标准化偏回归系数的正式对比检验（contrast test），而非仅描述"因类群而异"。

#### **H2｜人为过滤器替代假说（Anthropogenic filter replacement）** ★ 最具新意
**机理**：人类活动通过体型、生活史速度、生境宽度、营养级筛选物种，其作用轴与气候过滤轴**正交**。因此在高人类压力区，群落性状组成应更多由人为梯度而非气候梯度解释。

- **H2a**：性状组成方差中人为因子的独占解释份额随人类足迹升高而增加，气候份额相应下降（`气候 × 人类足迹` 交互显著为负）。
- **H2b**：人为过滤导致**功能同质化**——高人类压力网格的 SES.FDis / SES.FRic 显著低于预期。
- **H2c**：该效应在**恒温类群更强**（体型更大、生活史更慢、更易被直接捕猎与生境丧失影响）。
- **检验**：方差分解（climate | human | shared）逐格制图；交互项模型；SES 沿人类足迹梯度的分段回归。

#### **H2.5｜性状分布矩的解耦（Decoupling of trait distribution moments）** ★ 分析主框架

**为什么用"矩"而不是常规功能多样性指数**：FRic/FEve/FDiv 是多性状综合指标，机理解释含糊。相反，对**每个性状**分别计算群落性状分布的前四阶矩，可把不同的构建过程分离开：

| 矩 | 记号 | 生态学含义 | 指示的过程 |
|---|---|---|---|
| 一阶：加权均值 | **CWM** | 群落性状的**位置** | **方向性过滤**——环境偏好哪一端的性状值 |
| 二阶：加权方差 | **CWV** | 性状的**幅度** | **过滤强度 vs 限制相似性**——收窄=趋同，展宽=分化 |
| 三阶：加权偏度 | **CWS** | 分布的**不对称性** | **哪一侧尾部被截断**——负偏=大值被剔除 |
| 四阶：加权峰度 | **CWK** | 分布的**尖峭度** | **生态位填充**——高峰度=拥挤在最优值附近 |

**关键预测**：
- **H2.5a｜均值–方差解耦**：CWM 与 CWV 受**不同**环境轴支配。CWM 追随梯度的**方向**（如温度→体型，Bergmann 效应）；CWV 追随梯度的**严酷度/能量总量**（严酷→趋同→低方差）。
- **H2.5b｜人为压力的"无方向同质化"**：在高人类足迹区，CWM 位移有限而 **CWV 显著塌缩**——即功能同质化并非源于定向选择，而源于性状空间的整体截断。这是 H2b 的机理性表述。
- **H2.5c｜偏度识别过滤方向**：人为压力下体型 CWS 应显著变负（大体型被截断），且**恒温类群更强**（H2c）。
- **H2.5d｜恒温/变温差异**：变温类群的**热相关性状**（活动节律、繁殖模式）CWM 对温度轴响应更陡；恒温类群的 CWV 对生产力轴响应更陡。

> 所有矩均计算 **零模型标准化效应量（SES）**，因为方差与峰度会随物种丰富度机械性变化；SES 才能分离确定性过滤与丰富度效应。

#### **H3｜生态位填充 vs 扩张的类群差异（Niche packing vs expansion）**
延伸 Sun et al. 的描述性结果为机制性检验。

- **H3a**：随物种丰富度增加，恒温类群倾向**填充**（FRic 饱和、性状密度上升），变温类群倾向**扩张**（FRic 持续增长）。
- **H3b**：青藏高原的"体积大而密度低"格局在变温类群更极端。
- **检验**：FRic~richness 的分段/渐近回归；性状密度的零模型 SES。

#### **H4｜尺度依赖假说（Grain dependence）**
- **H4a**：环境过滤信号（SES.FD < 0）随粒度变粗而增强；50 km → 100 km 的信号增幅与类群扩散能力**负相关**（鸟类扩散强，增幅最小）。
- **检验**：两个粒度下重复全部分析；粒度×类群交互。

#### **H5｜跨类群一致性与替代性（Cross‑taxon congruence and surrogacy）**
- **H5a**：气候驱动的性状轴在四类群间空间一致性高；人为驱动的性状轴一致性低。
- **推论**：以单一类群（如鸟类）作为其他类群功能多样性的**替代指标，恰恰在保护决策最需要的人为压力区失效**。
- **检验**：跨类群 CWM/FD 的空间相关、Procrustes/协惯量分析（co‑inertia）、按人类足迹分层的一致性。

## 5. 分析流程 / Analytical workflow

```
01 建网格 ──► 02 物种名录与分类协调 ──► 03 性状整合与插补
                                              │
04 环境变量提取 ◄─────────────────────────────┤
                                              ▼
05 群落矩阵（4 类群 × 2 粒度）──► 06 群落性状指标
                                    ├ CWM（每个性状）
                                    ├ FRic/FEve/FDiv/FDis/RaoQ（PCoA 轴）
                                    ├ 性状体积/密度（dispRity）
                                    ├ 功能 β 多样性（betapart）
                                    └ 零模型 SES（999 次）
                                              ▼
07 统计建模
   ├ 7.1 四角法/max test 置换检验（性状–环境显著性，正确 α）
   ├ 7.2 空间 GLS / SAR（Matérn 相关结构）+ 空间分块交叉验证
   ├ 7.3 跨类群分层模型：环境 × 体温调节模式 交互 + 对比检验
   ├ 7.4 方差分解：气候 | 生产力 | 生境 | 人为 | 空间（逐格制图）
   ├ 7.5 随机森林 + SHAP（非线性与阈值）
   └ 7.6 分段 SEM（piecewiseSEM）：直接/间接路径
                                              ▼
08 稳健性
   ├ 双粒度（50/100 km）
   ├ 范围图 vs 观测记录（采样完整度校正）
   ├ 插补 vs 未插补
   ├ 零模型方案敏感性
   └ 系统发育不确定性（多棵树）
                                              ▼
09 出图（Nature 风格）+ 10 稿件
```

## 7. 审稿人雷区清单 / Reviewer landmines checklist

- [ ] CWM–环境回归的第一类错误 → **必须**用 fourth‑corner max test 或等价置换
- [ ] 空间自相关 → GLS/SAR + Moran's I 残差检验 + 空间分块 CV
- [ ] 共线性 → VIF < 5，变量筛选过程透明化
- [ ] 范围图的 commission error → 观测数据稳健性分析
- [ ] 采样偏差 → 完整度校正、努力量作协变量
- [ ] 性状插补 → OOB 误差、覆盖率、未插补敏感性
- [ ] 零模型选择 → 至少两种随机化方案
- [ ] MAUP → 双粒度
- [ ] 系统发育不确定性 → 多树重复
- [ ] 制图合规 → 审图号 GS(2023)2767 底图、九段线/南海附图完整

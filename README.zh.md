# 中国陆生脊椎动物群落性状的空间格局与驱动机制
### Spatial patterns and drivers of assemblage trait structure in Chinese terrestrial vertebrates

---

## 核心结论 / Headline

> **内温性缓冲了群落性状对环境的过滤。** 以科为重复单元（n = 33），变温类群（爬行、两栖）的群落性状–环境耦合强度是恒温类群（鸟、兽）的 **1.72 倍**（Wilcoxon *P* = 0.010）；热能量轴上 **1.68 倍**（嵌套混合模型 *P* = 0.023）；30 个「响应 × 环境轴」对比 **30/30** 方向一致。
> 与预期相反，变温类群对**当代人类压力**同样更敏感（**2.05 倍**，*P* = 0.0016）——这是留一纲检验中唯一 **5/5 情景全部显著**的项。
>
> **稳健性**：留一纲检验的 15 个组合中比值 **100% > 1**（1.39–2.69），方向稳健；但剔除任一纲后每组仅剩 5–13 科，单项显著性会丢失。
>
> **附带的方法学贡献**：把 CWM 直接对环境回归会把 **1.27–2.72 倍**的关联误判为显著，**21–54% 的具体结论被推翻**（第四角 max test 对照）。最极端者：爬行类"垂直生境–年降水"，朴素 *P* = 5×10⁻¹⁷⁵，正确检验 *P* = 0.054（不显著）。
>
> **范围图低估了多少（仅鸟类可检验）**：用 458 万条 GBIF 鸟类记录构建「观测群落」后，人类压力对分布范围 CWM 的效应是范围图的 **6.1 倍**（0.104 vs 0.017）；生境宽度方差的效应在范围图中为 −0.020 而观测数据中为 +0.120。该差异经**同网格对照**确认来自数据来源而非网格选择。兽/爬行/两栖的 GBIF 记录仅 3.5 万–10 万条，可用网格 163–170 个，不足以做同样检验。
>
> **一条不依赖任何模型的独立证据**：相邻网格之间，鸟类的功能组成周转仅为物种周转的 **19%**、哺乳类 34%、爬行类 **66%**——恒温类群的群落高度**功能冗余**，物种换掉了功能却没变。
>
> **保护含义（已用保护区数据验证）**：功能结构的跨类群一致性**仅存在于鸟–兽之间**（*r* = 0.63）。接到中国 1,028 个自然保护区上检验，这一替代性失效有直接后果——保护覆盖度只与**哺乳类**功能多样性正相关（+0.106，*P* = 0.012），对鸟类无关、对爬行类为负；鸟类与爬行类的保护空缺只有 **18%** 重合。机制清楚：保护区设立时把哺乳类列为主保护对象的占 **17.9%**，而爬行类仅 **1.1%**。
>
> **一个意外的地理结果**：仅用性状结构做无监督聚类，三个纲**各自独立**地把中国划成西北–东南两大功能区，其边界与**胡焕庸线**高度接近——而这条线并未作为任何输入。

## 方法上的四个关键决定 / Four decisions that matter

1. **重复单元 = 科，而非纲或网格。**
   以「纲」为单元只有 4 个重复（恒温 2 / 变温 2）；以「网格」为单元是伪重复（同一纲的所有格共用一个物种库与性状矩阵）。本研究以 **33 个科**（恒温 21 / 变温 12）为重复，并以 `纲/目` 嵌套随机效应吸收系统发育非独立性。两篇对标文献均未处理这一问题。

2. **性状分布的四阶矩，而非仅多元多样性指数。**
   均值 = 方向性过滤；方差 = 过滤强度 vs 限制相似性；偏度 = 哪一侧尾部被截断；峰度 = 生态位填充。结果显示三者并不冗余（见结果报告 §5）。

3. **零模型按唯一丰富度值计算。**
   零分布只依赖丰富度 *S*，故按唯一 *S* 计算一次即可——这是**精确**的等价变换，使 999 次重复在单机可行（比逐格模拟快 1–2 个数量级）。

4. **性状分布矩的 SES 逐格保存，使探索分析成为可能。**
   脚本 05 为每格、每性状、每阶矩都保存了零模型 SES（共 40 个变量/纲）。这使得后续可以直接问"**哪个**性状在**哪里**被过滤"（Fig 8）、"性状结构把中国分成哪几个功能区"（Fig 9），而无需重算零模型。

5. **空间自回归而非普通回归。**
   OLS 残差的 Moran's I 在 **100%** 的模型中显著；SAR（λ 中位数 0.959）使 AIC 中位数改善 **2,092**。

## 诚实的限制 / Honest limitations

- **体温调节模式与「纲」几乎共线**（2 纲恒温 vs 2 纲变温），这为任何中国境内的检验设置了统计功效天花板。科级设计缓解但不能消除该问题；结论的稳健性同时依赖**方向一致性（30/30）**与单个 *P* 值。保守的嵌套混合模型仅在热能量轴上显著（*P* = 0.023）。
- **专家范围图对细尺度土地利用不敏感**。此项已量化：观测群落给出的人为效应约为范围图的 **5.6 倍**（§5f），故本文报告的人为效应是**保守下界**。哺乳、爬行、两栖的 GBIF 记录已下载，可同法扩展至四个类群。
- **最大寿命缺失 19–55%**，已排除出核心性状集；**两栖类食性缺失 68%**，故两栖类的营养维度缺席。均如实报告于 `table_S3` / `table_S6`。
- **两栖类的体重与活动节律实测率仅 8% 与 11%**，这是中国两栖类研究的真实空白而非整合疏漏。原先的「功能超离散」结论已**撤回**。改用四个高实测率性状（体长 65%、垂直生境 62%、生境宽度 61%、分布范围 100%）重做后，215 个物种给出 SES = **+0.10**，即**无可检出的功能结构**——这与鸟、兽、爬行的强烈聚集形成对比，本身是一个可用结论（§5d）。

## 制图合规 / Cartographic compliance

**分析网格**建立在自然资源部标准地图 **GS(2023)2767** 的大陆边界上（Albers 等积投影）。

**制图底图**改用南海诸岛按**真实地理位置**绘制的省级矢量边界（范围至 3.83°N）配合独立的十段线图层，得到国内期刊常见的紧凑版式。原 GS(2023)2767 数据把南海诸岛预置在右侧附图框内，出图后右下角留有大片空框，且诸岛与大陆的相对位置不真实。

> **一处已修正的数据问题**：GS(2023)2767 的省面图层把南海诸岛预置在附图框内，建网格时会在那里生成 32 个（50 km）网格，其反投影经纬度落在西太平洋（129–136°E, 25–27°N），把正确的物种组成配上了错误位置的气候。这些网格已用 `scs_inset` 标记并在全部分析与制图中排除（受影响最大的是爬行类，占其 0.77%）。
